# Phase 3 — Implementation Gate

## Input

- Approved Design；Acceptance Criteria；允许/禁止修改清单
- 来源：Design Gate

## Goal

按批准设计实施最小改动。

## Allowed

- 改允许清单内文件、小步 commit、跑测试

## Forbidden

- 扩大范围、跨 Phase 偷渡、改设计未覆盖的边界

## Required artifacts

- 实现 + 自测 + 逐改动点 Before/After/Reason

## Acceptance

- 全量回归 EXIT=0（或失败全部归类且与产品行为无关）
