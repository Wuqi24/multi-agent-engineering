# Phase 0 — Audit Gate

## Input

- 项目路径；项目约束说明（工作台/SOP，如存在）
- 来源：任务发起

## Goal

只读摸清现状，输出风险、边界、ROI 排序。

## Allowed

- 读文件、跑只读诊断、出报告

## Forbidden

- 改代码、建目录、提交、进实施

## Required artifacts

- 审计报告（Current State / Boundaries / Parallelism / Conflict Files / ROI）

## Acceptance

- 边界与瓶颈明确；"值得做什么"排序明确；无任何文件改动
